1. Задача 1: `62.187.216.242/26`
2. Задача 2: `144.17.221.246/17`

## Задание 1. Определение класса IP-адреса

1. `62.187.216.242`  
   Первый октет `62`, двоичный вид `00111110`. Первый бит равен `0`, значит это класс `A`.

2. `144.17.221.246`  
   Первый октет `144`, двоичный вид `10010000`. Первые два бита равны `10`, значит это класс `B`.

3. `196.147.69.227`  
   Первый октет `196`, двоичный вид `11000100`. Первые три бита равны `110`, значит это класс `C`.

4. `227.147.196.69`  
   Первый октет `227`, двоичный вид `11100011`. Первые четыре бита равны `1110`, значит это класс `D`.

## Задание 2. Вычисление адреса сети

- IP-адрес: `62.187.216.242`
- Маска: `/26`
- Маска в двоичном виде: `11111111.11111111.11111111.11000000`

```text
62.187.216.242  = 00111110.10111011.11011000.11110010
/26            = 11111111.11111111.11111111.11000000
---------------------------------------------------
Адрес сети     = 00111110.10111011.11011000.11000000
```

Ответ: адрес сети `62.187.216.192`.

## Задание 3. Вычисление адреса узла

- IP-адрес: `62.187.216.242`
- Маска: `/26`
- Обратная маска: `00000000.00000000.00000000.00111111`

```text

---------------------------------------------------
Адрес узла     = 00000000.00000000.00000000.00110010
```

## Задание 4. Порядковый номер узла

Порядковый номер узла получается переводом адреса узла из двоичного вида в десятичное число.

1. `0.0.0.50`  
   Двоичный вид: `00000000.00000000.00000000.00110010`  
   Ответ: `50`

2. `0.0.93.246`  
   Двоичный вид: `00000000.00000000.01011101.11110110`  
   Вычисление: `93 * 256 + 246 = 24054`  
   Ответ: `24054`

3. `0.0.0.227`  
   Двоичный вид: `00000000.00000000.00000000.11100011`  
   Ответ: `227`

4. `0.0.4.69`  
   Двоичный вид: `00000000.00000000.00000100.01000101`  
   Вычисление: `4 * 256 + 69 = 1093`  
   Ответ: `1093`
